Publishing Standard

Built for governed growth.

Each public resource points to a clean HTML page, while the permanent governance record remains connected through the OLS Knowledge Inventory, Content ID, website slug, resource type, theme, and publication status.

HTML First

OLS resources are published as HTML pages for search visibility, internal linking, public readability, future AI discovery, and website indexing.

No Public Word Downloads

Word documents remain internal governed source files. Public resources appear as website pages, with protected PDF options reserved for future use if needed.

Image Ready

Cards are structured so image assets can be added later using the approved naming standard without redesigning the page.
